# Detective Foodie

## Description
This is a narrative-driven detective game set in my old neighborhood.  
You play as a detective returning to familiar streets to solve a long-forgotten case. Memories, locations, and time itself play a key role in uncovering the truth.

The game focuses on exploration, dialogue, and environmental storytelling rather than fast-paced action.

---

## Setting & Inspiration
- Old residential neighborhood with strong personal and historical ties  
- Themes: memory, guilt, time, and truth  

---

## Gameplay Features
- Story-focused detective gameplay  
- Exploration of an interconnected neighborhood  
- Dialogue-based investigation  
- Puzzle-solving and clue collection  
- Single-player experience  

---

## Controls
- **WASD** – Move  
- **Mouse** – Look  
- **E** – Interact  
- **I** – Inventory  

---

## Running the Game from Source Code

1. Clone or download the project source code:
   ```bash
   git clone https://github.com/adamcristian297-byte/detective-foodie

2. Extract the project folder if needed.
3. Open the project in the appropriate game engine (Unity).
4. Run the game directly from the editor by pressing **Play**.

---

## Installation Instructions

1. Download the game archive from the submission page.
2. Extract the `.zip` file to any location on your computer.
3. Open the extracted game folder.
4. Run the executable file:
   - **Windows:** `austria.exe`
5. The game will start automatically.
